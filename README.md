# DORIS

## Intro/简介

This is a special version of DORIS that supports [teresa](https://github.com/aprilab-dev/teresa). This version supports a variety of Chinese domestic SAR satellites, currently supporting:
    - GF3;
    - LT1;
    - BC3 (from Spacety).
More sensors will be supported in the future.

The current version is maintained by the [APRILAB](https://joinus.aprilab.dev) group of NWPU. We use GPLv3 license following the original [doris](https://github.com/TUDelftGeodesy/Doris/blob/master/LICENSE.txt).

这是一个支持 [teresa](https://github.com/aprilab-dev/teresa) 的 DORIS 特别版本。该版本支持多种国产 SAR 卫星，目前支持：
  - GF3 系列；
  - LT1 系列；
  - 天仪卫星系列。
未来将支持更多传感器。

当前版本由西北工业大学 [APRILAB](https://joinus.aprilab.dev) 团队维护。我们遵循原始 [doris](https://github.com/TUDelftGeodesy/Doris/blob/master/LICENSE.txt) 的 GPLv3 许可证。

## Installation/安装

Unless you are an experienced DORIS user, it is not recommended to use this version alone for data processing. It is recommended to use it together with [teresa](https://github.com/aprilab-dev/teresa). For installation instructions for both teresa and DORIS, please refer to [teresa](https://github.com/aprilab-dev/teresa).

除非你是资深 doris 用户，否则不建议单独使用此版本进行数据处理。建议配合 teresa 使用，teresa 和 doris 的安装请参见 [teresa](https://github.com/aprilab-dev/teresa)。
